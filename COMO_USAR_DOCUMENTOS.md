## 🖨️ CONVERTER HTML PARA PDF

### **Método 1: Google Chrome (MAIS FÁCIL)**

1. **Abra o arquivo:**
   ```
   Clique em: RESUMO_EXECUTIVO.html
   (Abre automaticamente no navegador)
   ```

2. **Imprima para PDF:**
   ```
   Pressione: Ctrl + P (Windows) ou Cmd + P (Mac)
   ```

3. **Configure:**
   ```
   Destino: "Salvar como PDF"
   Orientação: Retrato
   Margens: Padrão
   ```

4. **Salve:**
   ```
   Clique: "Salvar"
   Escolha pasta e nome
   Pronto! ✓
   ```

### **Método 2: Firefox**

1. Abra RESUMO_EXECUTIVO.html
2. Pressione Ctrl + P (ou Cmd + P)
3. Selecione "Salvar como PDF"
4. Clique "Salvar"

### **Método 3: Microsoft Edge**

1. Abra RESUMO_EXECUTIVO.html
2. Pressione Ctrl + P
3. Selecione "Salvar em PDF"
4. Clique "Salvar"

### **Método 4: Online (se não tiver acesso ao arquivo local)**

Se estiver acessando pelo navegador:
1. Clique menu ⋮ (três pontos)
2. Selecione "Imprimir"
3. Escolha "Salvar como PDF"
4. Configure e salve

## 🔧 TROUBLESHOOTING

### **Problema: HTML não abre no navegador**
```
Solução:
1. Clique direito no arquivo
2. "Abrir com"
3. Selecione: Chrome, Firefox, Edge ou Safari
4. Pronto!
```

### **Problema: PDF fica com qualidade ruim**
```
Solução:
1. Abra HTML novamente
2. Na hora de imprimir (Ctrl+P):
   - Selecione "Mais configurações"
   - Marque: "Gráfico de fundo"
   - Mude orientação para "Paisagem" se necessário
3. Salve com qualidade 150%
```

### **Problema: Arquivo CSV não abre no Excel**
```
Solução:
1. Abra Excel normalmente
2. Arquivo → Abrir
3. Mude filtro para "Todos os arquivos"
4. Selecione CSV
5. Na hora de abrir, escolha delimitador "Vírgula"
```

### **Problema: Números não batem com meus dados reais**
```
Solução:
1. Abra: GUIA_VERIFICACAO_CALCULOS.md
2. Siga o passo a passo para validação
3. Ajuste os números com dados reais
4. Recalcule usando as fórmulas
```
